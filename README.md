# Portfolio — GitHub Pages

ไฟล์นี้พร้อมนำไปอัปโหลดขึ้น GitHub ได้ทันที

## โครงสร้าง
- `index.html` — หน้าเว็บหลัก
- `style.css` — ตกแต่งเว็บ
- `script.js` — JavaScript
- `images/1.jpg` ถึง `images/12.jpg` — หน้า Portfolio ตามลำดับ

## เปิด GitHub Pages
1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด โดยให้ `index.html` อยู่ระดับบนสุด
3. ไปที่ Settings → Pages
4. เลือก Deploy from a branch
5. เลือก branch `main` และ folder `/ (root)`
6. กด Save แล้วรอ GitHub Pages สร้างเว็บไซต์
